#  Jude Bellingham ASCII Art using Python

This project converts a real image of **Jude Bellingham** into an **ASCII-style image** using core Python programming concepts.  
The project was developed as part of a **Minor II assignment** to strengthen Python fundamentals, logical thinking, and creativity.

---

##  Project Overview

ASCII art is a visual representation of images using text characters such as `@`, `#`, `*`, `+`, and `.`.  
In this project, a photograph of Jude Bellingham is processed and converted into an ASCII portrait where symbols form his facial features.

---

##  Objectives

- Apply **core Python concepts** like loops and conditional statements
- Use logical thinking to map image pixels to ASCII symbols
- Generate a recognizable ASCII portrait from a real image
- Improve creativity and problem-solving skills using Python

---

##  Concepts Used

- Python `for` loops
- Conditional logic
- Pixel-to-symbol mapping
- Image processing
- ASCII visualization
